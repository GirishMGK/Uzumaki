# HRM (hrm_tool/) -- vendored FastAPI backend, run in-process by
# _pages/hrm.py. Left unpinned like everything else above so pip
# resolves one version set shared with streamlit's own requirements
# (notably starlette/websockets/python-multipart) -- the original repo's
# pinned fastapi==0.115.0 conflicts with the starlette version streamlit
# itself now requires internally; letting fastapi float resolves a version
# compatible with both. psycopg is deliberately omitted: SQLAlchemy only
# imports a DB driver based on the connection URL's scheme at engine-creation
# time, and the desktop/in-process mode this hub uses always connects via
# sqlite:///..., so nothing in app code ever imports it.

# Pinned (not left to float like the deps above): passlib 1.7.4's bcrypt
# backend probes bcrypt.__about__.__version__ to detect the installed
# version -- removed in bcrypt>=4.1 -- which makes passlib misdetect and
# raise "password cannot be longer than 72 bytes" even for short passwords
# (hit live: the seeded "ChangeMe!2026" admin password triggered it on
# first HRM launch). hrm_tool/backend/requirements.txt already pins the
# same version for this reason; mirror it here since this file is what
# actually gets installed for the packaged .exe.
